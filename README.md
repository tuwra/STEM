# مشاريع STEM · مبادرة نود

## إشارة 🤟
منصة تواصل بين الصم والسامعين، وتعليم لغة الإشارة. تعمل بالكامل داخل المتصفح.

- **محادثة باتجاهين:** الأصم يأشّر فتتحول إشارته لكلام مسموع، والسامع يتكلم فيتحول كلامه لنص كبير على الشاشة.
- **اليدين:** يتعرف على إشارات بيد وحدة وباليدين (MediaPipe Hands، 21 نقطة لكل يد).
- **تعلّم الإشارة:** دروس وتمارين واختبار عشوائي، والموقع يصحح حركة يدك مباشرة.
- **أضف إشارة:** تعلّم الموقع أي إشارة جديدة خلال ثواني (تصنيف kNN)، مع صورة ووصف للمتعلمين.
- عبارات سريعة، ونطق عربي، وحفظ ونقل الإشارات بملف.
