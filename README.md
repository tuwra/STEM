# مشاريع STEM · مبادرة نود

## إشارة 🤟
مترجم لغة الإشارة إلى صوت عربي، يعمل بالكامل داخل المتصفح.

- يتعرف على اليد بالكاميرا باستخدام MediaPipe Hands (21 نقطة على مفاصل اليد).
- 7 إشارات جاهزة + وضع «علّمني» لتعليم أي إشارة جديدة خلال ثواني (تصنيف kNN).
- يكوّن الجمل وينطقها بصوت عربي.

**جرّبه:** https://tuwra.github.io/STEM/ishara/
